# Brand

Identity: everything that makes a brand look like itself.

| Category | What goes in it |
| --- | --- |
| [Logos](logos/) | Logos, logomarks and wordmarks |
| [Monograms](monograms/) | Letter marks and initials |
| [Brand kits](brand-kits/) | Full identity packs with logo, colors, type and usage rules |
| [Style guides](style-guides/) | Brand books and guidelines |
| [Mascots](mascots/) | Brand characters and mascots |
| [Brand patterns](brand-patterns/) | Patterns and graphic devices built from a brand |
| [Favicons](favicons/) | Favicons and tiny brand marks |
| [Email signatures](email-signatures/) | Email signatures |

Each design gets its own folder inside a category. See [Adding a design](../README.md#adding-a-design).
