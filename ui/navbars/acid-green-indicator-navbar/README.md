# Acid-green indicator navbar

A glowing green capsule glides under a row of solid icons. Small green particles hover above and below the active position.

## Files

- [Open the standalone design](source/design.html). Select any destination or use the arrow keys to move the indicator.
- Add `#ocean` to switch palettes or `?t=2.56#ocean` to freeze the preview.
- [Exports](exports/) contains a PNG and an H.264 MP4 for every colorway.

## Changing it

The CSS variables at the top of `source/design.html` control the palette. Copy a palette block, rename it, then run `python3 .github/scripts/export_design.py ui/navbars/acid-green-indicator-navbar` from the repository root.
