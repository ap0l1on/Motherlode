# Violet signal sidebar

## Files

- [Open the standalone design](source/design.html). Use the round fold control to change the sidebar width, then select a destination with the pointer or keyboard.
- Add `#ocean` to switch palettes or `?t=2.72#ocean` to freeze the preview.
- [Exports](exports/) contains a PNG and an H.264 MP4 for every colorway.

## Changing it

The CSS variables at the top of `source/design.html` control the palette. Copy a palette block, rename it, then run `python3 .github/scripts/export_design.py ui/sidebars/violet-signal-sidebar` from the repository root.
