# Amber perimeter download

An amber light travels around a nearly black capsule while its numeric progress glows at the center. The border brightens around the completed state.

## Files

- Open [the design](source/design.html) in a browser and append `#ember` to select that colorway. Add `?t=1.6#ember` after the filename to show the export still.
- [The exports folder](exports/) contains a PNG and an H.264 MP4 loop for each colorway.
- [The font folder](source/fonts/) includes the font files and their licenses.

## Changing it

Click or press Enter to replay. This is the amber perimeter control from the three-button demonstration.

The custom properties at the top of `source/design.html` define each palette. Copy a palette block, give it a new colorway name, then run `python3 .github/scripts/export_design.py ui/buttons/amber-perimeter-download` from the repository root.
